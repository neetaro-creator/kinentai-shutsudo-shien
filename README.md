# 緊援隊 出動支援アプリ

緊急消防援助隊の出動にあたり、滋賀県大隊応援等実施計画の判定表・編成・手順・様式を手元で素早く確認するための静的Webアプリです。ビルド不要・依存なし。一度開けばオフラインでも動作します（Service Worker）。

## 重要：参考表示です

本アプリの表示は**参考**です。**実際の出動準備・出動は、必ず消防庁からの連絡に従ってください。** 表示と実際の指示が異なる場合は、指示を優先します。

## データの出典と版

- 出典：緊急消防援助隊滋賀県大隊応援等実施計画
- 版：令和8年8月版（2026-08-01）
- 転記日：2026-11-08
- 計画は毎年4月・8月ごとに改正されます。版が古い場合は、アプリ上で警告が出ます。

## 色の意味について

判定の帯などに使っている色の意味は**案**です。計画に定められたものではありません。印刷時は色に頼らず、文字と枠で判別できるようにしています。

## 地震情報の取り込み（F8）

画面上部の「地震情報を取り込む」で、P2P地震情報の公開API（`api.p2pquake.net`）から直近7日間の地震を取得し、選んだ地震の最大震度・震央・観測点・大津波警報から状況入力を自動入力します。仕様は `取込仕様.md`。

- 自動入力は**要確認**です。値は手で直せます。アクションプラン・噴火警報・国家的非常災害は取り込まず、必ず手入力します。
- 政令市・東京特別区の判定は、観測点名と `data/cities.json` で行います。津波予報区の都道府県への対応は `data/tsunami_area_map.json` です。
- 回線やAPIに失敗しても、手入力で判定できます（判定は止まりません）。外部通信が職場のネットワークで通るかは未確認です。

## アクションプランの扱い（南海トラフ・首都直下・日本海溝千島海溝）

アクションプランに該当と入力すると、別表Ａ・別表第7の判定は使わず、`data/action_plans.json` から滋賀県大隊の扱い（応援編成区分・応援先・進出拠点・出動規模など）と、アクションプランの流れ・自本部の動きを根拠付きで表示します。内容は参考で、実際の出動・編成は消防庁長官の指示によります。

- 出典は各アクションプラン本文のページ画像です（南海トラフ令和2年7月17日改定、首都直下令和3年3月12日改定、日本海溝・千島海溝令和7年3月25日）。各項目に原文の頁と引用を付けています。
- 内容は画像から読み取り、別のモデルがページ画像と照合しています（182件中、支持150件、一部修正32件、不支持0件）。**原本との人の照合は未実施**です。
- 改定されたら `data/action_plans.json` を作り直してください。

### アクションプラン「該当の可能性」の注意

状況入力が3つのアクションプランの適用基準に当たりそうなとき、判定の帯の下に「該当の可能性」を出します（仕様は `AP該当ヒント仕様.md`、基準は `data/ap_rules.json`）。確定ではありません。適用を決めるのは消防庁長官で、アプリは判定を変えません。該当するときは、利用者が「アクションプラン該当」を選びます。入力から確認できない条件（観測した都道府県、震央地名、3地域すべての震度など）は「確認すること」として出します。
